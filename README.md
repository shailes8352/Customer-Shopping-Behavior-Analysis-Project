# Customer Shopping Behavior Analysis Project 🛍️

An end-to-end data analytics project analyzing retail customer shopping patterns, revenue generation, and demographic insights using SQL, Python, and Power BI.

## 📁 Files Included
* *Customer_behavior.sql*: SQL scripts used for querying and data extraction.
* *customer_shopping_behavior.ipynb*: Jupyter Notebook containing data cleaning and exploratory data analysis (EDA) in Python.
* *Shopping_Behavior.pbix*: Interactive Power BI dashboard visualizing key metrics and insights.
* *customer_shopping_behavior.csv*: Raw dataset file.

## 🚀 Key Insights & Features
* Analyzed total customers, revenue generation, average purchase amount, and review ratings.
* Examined category performance (Clothing, Accessories, Footwear).
* Evaluated subscriber vs. non-subscriber trends and gender distribution.
